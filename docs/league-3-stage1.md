# MCGG LEAGUE 3.0 — этап 1 (тестовая версия)

## Область изменений
- Существующий основной сайт, D1 и данные турнира 4×4 не изменяются.
- Файл `migrations/0001_league_core.sql` — **проект миграции для отдельной тестовой D1**. На рабочей базе не выполнять до резервного копирования и проверки.
- Ручной ввод фасткапа в тестовой ветке: черновики в локальном браузере, без серверного начисления PTS.
- Telegram-бот и вход по Telegram ещё не подключены.

## Правила первой версии
- Фасткап 8: восемь зарегистрированных участников; по итогам точно известны только 1, 2 и 3 места.
- Все восемь получают 1 сыгранную игру, ТОП-3 — только трое, ТОП-1 — только победитель.
- Победителю +1 PTS; остальные 0. Дублирующиеся ники проверяются до сохранения.
- В случае замены игрока оператор редактирует список фактически игравших.
- Сохранять один черновик на один ID турнира; без автоматической публикации.
- Для продакшн-бота необходимы атомарные подтверждения и audit log.

## Перед промышленным развёртыванием
1. Снять и проверить резервную копию D1 и исходной Google Sheets.
2. Создать отдельную D1 для staging и применить схему только там.
3. Добавить авторизованные API создания/редактирования и транзакционное подтверждение.
4. Протестировать дедупликацию Telegram, правила PTS, смену ника и восстановление резервной копии.
5. После проверки перенести схему на основную D1 *дополнительно*, без удаления старых таблиц.
